Diferencias entre una aplicación interna y una externa

Primero que nada, antes de aprender cómo securizar distintos tipos de aplicaciones, tenemos que entender las diferencias entre aquellas que son internas y las que se utilizan de manera externa.

Las aplicaciones web internas son aquellas que se desarrollan y se utilizan dentro de una organización o empresa. Están diseñadas para cumplir con las necesidades específicas de la organización, como ser por ejemplo un seguimiento de inventario/stock, la gestión de proyectos, la administración de recursos humanos, entre otros.

Las aplicaciones web internas son accesibles solo por los empleados de la empresa que las utilizan y se implementan generalmente para mejorar la eficiencia y la productividad de las tareas que se suelen hacer diariamente.

Por otro lado, las aplicaciones web externas, son aquellas que están diseñadas para ser utilizadas por personas fuera de la organización que es su creadora. Estas aplicaciones suelen ser consumidas o consultadas para obtener determinados datos que otro sistema o usuario pueda estar necesitando. Hay que tener en cuenta que las aplicaciones web externas pueden ser gratuitas o de pago, como así también tener acceso totalmente público o restringido.

En cuanto a seguridad, ambos tipos de aplicaciones tienen particularidades. Las aplicaciones internas se utilizan dentro de una organización y, por lo tanto, están protegidas GENERALMENTE por la red interna de la misma, mientras que las aplicaciones externas, al utilizarlas on line, están mucho más expuestas constantemente a amenazas de seguridad externas. Esto significa que, deben tener medidas de seguridad adicionales para proteger los datos de los usuarios.
