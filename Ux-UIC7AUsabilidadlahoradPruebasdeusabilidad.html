¿Para qué sirven?

  • Para demostrar hipótesis con hechos reales.
  • Para entender el comportamiento de los usuarios.
  • Para evitar discusiones innecesarias con el equipo de trabajo.
  • Para encontrar problemas especi?ficos, que solo pueden ser detectados realizando una prueba.
  • Para ver si estamos en el camino correcto.


En las etapas de research y prototipado, la exploración nos servirá para determinar las hipótesis del negocio, refinar el perfil de los usuarios y relevar su modelo mental. En la fase de validación vamos a comprobar si nuestro producto efectivamente soluciona los problemas de las personas. También podremos identificar potenciales problemas de usabilidad y medir la performance de las interfaces diseñadas.
