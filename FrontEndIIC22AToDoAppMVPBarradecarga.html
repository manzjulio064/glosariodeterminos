Barra de carga

Animando nuestra aplicación

En la actualidad, las aplicaciones modernas se caracterizan por ser dinámicas, ya que brindan al usuario la posibilidad de interactuar mediante distintos tipos de acciones, ofreciendo una respuesta como reacción a dicha interacción.

Este proceso de acción y reacción se da en tiempo real, pero no siempre en forma inmediata.

Como ya sabemos, existen múltiples situaciones en las que, frente a un pedido del usuario, la aplicación necesita consumir datos que se encuentran almacenados fuera de ella (como por ejemplo, en una base de datos), lo que requiere realizar una (o varias) peticiones a servicios y servidores externos para obtener dicha información.

Según lo que vimos algunas clases atrás, este proceso de peticiones y respuestas ocurre de manera asincrónica, es decir, diferida en el tiempo. ?

Ahora bien, ya sea que la reacción se produzca de manera más o menos inmediata o con cierta demora, debemos asegurarnos de informar al usuario que dicho proceso se encuentra en curso.

En otras palabras, para garantizar que nuestra aplicación mantenga una sensación de fluidez y dinamismo, es necesario que aun en esos momentos en los que estamos procesando un pedido del usuario, le hagamos saber que la aplicación se encuentra activa y trabajando para poder ofrecerle la respuesta esperada.

Para ello, una de las estrategias que tenemos disponibles es el uso de animaciones.? Por supuesto que esta no es la única función que cumplen las animaciones, pero este quizás es uno de sus usos más frecuentes.

En esta oportunidad, veremos uno de los recursos más antiguos y utilizados para indicar el momento en el cual nuestra aplicación se encuentra procesando información: la barra de carga o progress bar.

Paso a paso: construyendo una progress bar

Para poder construir nuestra barra de progreso comenzaremos creando un archivo index.html, el cual contendrá la estructura básica de este tipo de documentos: 

        
                  <!DOCTYPE html>
                  <html lang="en">
                  <head>
                      
                      
                      
                      Barra de Progreso
                  </head>
                  <body></body>
                  </html>

TIP: Puedes inicializar rápidamente un documento HTML en tu VS Code tipeando el carácter “ ! ” seguido de la tecla Tab.

Ahora que ya tenemos el documento inicializado, incorporaremos dentro del body los elementos necesarios para renderizar nuestra barra: 

        
                  <body>
                      <div id="progreso">
                          <div id="barra">10%</div>
                      </div>
                      <button id="iniciar-carga">Comenzar Carga</button>
                  </body>

Seguidamente, incorporaremos algunos estilos. Para ello, crearemos un archivo styles.css (no olvides incluir este archivo en el index.html) y agregaremos los siguientes estilos: 

        
                  body {
                      height: 100vh;
                      display: flex;
                      flex-direction: column;
                      justify-content: center;
                      align-items: center;
                    }

                    #progreso {
                      width: 30%;
                      border: 2px solid rgb(27, 27, 27);
                      box-shadow: 3px 3px 5px darkgray;
                    }

                    #barra {
                      width: 0%;
                      height: 30px;
                      background-color: #04aa6d;
                      text-align: center;
                      line-height: 30px;
                      color: white;
                    }

                    #iniciar-carga {
                      margin-top: 1rem;
                      padding: 0.3rem;
                      border-radius: 5px;
                      box-shadow: 3px 3px 5px darkgray;
                      cursor: pointer;
                    }

Finalmente, utilizaremos Javascript para dar vida a nuestra barra de carga. Para ello, crearemos nuestro archivo index.js (no olvides vincularlo en el index.html). En este incluiremos el siguiente código: 

        
                  // Simulamos un proceso que demora 5 segundos en completarse
                  const tiempoDeCarga = 5000;

                  function animarBarra() {
                      // Seleccionamos el elemento barra
                      let elem = document.getElementById("barra");

                      // Inicializamos el progreso en 0, para asegurarnos
                      // que siempre arranque desde el principio
                      let width = 0;

                      // Calculamos el progreso en base al tiempo total de carga,
                      const progresoSobreTiempoTotal = tiempoDeCarga / 100;

                      // Creamos un intervalo que se repita en el tiempo que calculamos
                      // para ir incrementando el progreso.
                      let id = setInterval(incrementarProgreso, progresoSobreTiempoTotal);

                      function incrementarProgreso() {
                          // Si el progreso esta completo, detenemos el programa
                          if (width >= 100) {
                          clearInterval(id);
                          } else {
                          width++;

                          // Modificamos el DOM, para impactar el nuevo progreso.
                          elem.style.width = width + "%";
                          elem.innerHTML = width + "%";
                          }
                      }
                  }

                  document.querySelector("#iniciar-carga").addEventListener("click", animarBarra);

¡Excelente! A esta altura ya tienes una barra de carga animada y totalmente funcional.?
