Práctica preevaluación

¡Felicidades! Hemos recorrido un largo camino hasta ahora y esta es nuestra primera parada en boxes antes de nuestro punto de control, que tendrá lugar en la próxima clase. La idea es que en esta clase podamos desarrollar proyectos que sean como simulacros preparatorios para nuestra primera evaluación.

Por eso, para que tengan una gran experiencia durante la evaluación, hemos preparado dos ejercicios que se realizarán en el encuentro presencial, uno de ellos guiado por el profesor y el segundo realizado en las mesas de trabajo con nuestros compañeros. Ah, y no se preocupen, porque en esta clase tampoco tendremos nuevos contenidos asincrónicos. Es decir, lo único que tenemos que hacer es estar afilados con los materiales de las clases anteriores.
Como sugerencia, te dejamos algunos consejos para que estudies y estés lo más preparado posible para los ejercicios de esta práctica de evaluación previa:

  • Revisar cómo se configuran Spring Cloud Eureka, API Gateway y Spring Cloud Config.
  • Revisar los conceptos sobre la creación de una API REST.
  • Revisar los conceptos de la base de datos (MySQL).

¡Muy bien! Por lo tanto, creemos que con estas pautas y consejos estarás equipado con los mejores recursos para esta clase.
