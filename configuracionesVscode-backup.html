🔄 Backup y Restauración de Visual Studio Code

Este sitio te permite descargar y restaurar tu configuración personalizada de Visual Studio Code, incluyendo: Settings, Keybindings, Snippets, Tasks, MCP Server, UI State, Extensions, Profiles y Prompts.

📦 Descargar respaldo

📜 Descargar scripts de respaldo y restauración



Para ejecutar los scripts, primero dales permisos si los requiere con:

chmod +x backupConfVisualSCode.sh
  chmod +x RestauracionConfiguracionVisualStudioCode.sh

Y luego ejecútalos así desde la terminal:

./backupConfVisualSCode.sh
./RestauracionConfiguracionVisualStudioCode.sh

🧪 Procedimiento de respaldo

1. Ejecuta el siguiente script desde la terminal (Linux, macOS, Git Bash en Windows):

./backupConfVisualSCode.sh

2. Se generará la carpeta vscode-backup/ con:

  • Tu configuración de usuario
  • Snippets, keybindings, tasks
  • Extensiones instaladas

3. Comprime esa carpeta como .rar o .zip para resguardarla.

♻️ Procedimiento de restauración

IMPORTANTE: Antes de ejecutar el script de restauración, debes descargar el archivo vscode-backup.rar y descomprimirlo en el mismo directorio del script. De lo contrario, la restauración fallará.

1. Descomprime el archivo descargado.

2. Ejecuta desde la terminal:

./RestauracionConfiguracionVisualStudioCode.sh

3. Esto restaurará tu entorno exactamente como lo tenías.

☁️ Sincronización automática (Settings Sync)

También puedes sincronizar toda tu configuración con GitHub o Microsoft mediante la opción integrada de VS Code.

  1. En VS Code, presiona F1 o Ctrl+Shift+P.
  2. Escribe y selecciona: Settings Sync: Turn On.
  3. Inicia sesión con tu cuenta de GitHub o Microsoft.
  4. Selecciona los elementos a sincronizar:
  • Extensiones
  • Configuración (settings.json)
  • Atajos de teclado
  • Snippets
  • Temas

🔁 En una nueva instalación, repite los pasos y se restaurará automáticamente toda tu configuración si previamente realizo backup en github.
