El Taller de Data Analytics

¿Qué vas a encontrar en el Taller de Data Analytics?

En este taller les proponemos explorar el universo de los datos, para eso desarrollaremos más habilidades blandas que les permitirán tener un análisis completo de este recurso. Además, tenemos dos sorpresas a la mitad y al final del recorrido donde se verán desafiados a resolver diferentes situaciones.

Prepárense para aprender, divertirse y como siempre, seguir construyendo lazos para el trabajo colaborativo.



¿Cuáles son los objetivos del Taller?

  • Conocer la importancia de las estructuras de datos para el análisis y la toma de decisiones en un producto digital.
  • Utilizar los conocimientos adquiridos en Base de Datos y Gestión de Productos Digitales I para aplicar a las etapas de un proceso analítico: manipulación, modelado y visualización.
  • Manejar herramientas necesarias para el análisis de datos.
  • Aprovechar lo aprendido en el taller de UX para la correcta visualización y comunicación de resultados.
