Patrones de seguridad

En la actualidad, la seguridad de la información es un tema muy importante para las empresas que manejan datos sensibles de sus clientes. Por esta razón, se han desarrollado diversos patrones de seguridad para garantizar la protección de la información en línea.

Entre estos patrones se encuentran OAuth 2.0, Open ID Connect (OIDC), Json Web Token (JWT) y OIDC Discovery. A lo largo de esta clase, veremos en detalle cada uno de ellos, mientras tanto a continuación te dejamos un “pantallazo” de sus características más importantes para que los vayas conociendo.

  • OAuth 2.0es un protocolo de autorización que permite a los usuarios de una aplicación dar acceso a sus recursos a terceros sin tener que compartir sus credenciales de acceso. En lugar de eso, se genera un token de acceso que le da al tercero acceso limitado a los recursos del usuario. OAuth 2.0 se utiliza comúnmente en aplicaciones web y móviles para permitir que los usuarios inicien sesión en una aplicación usando sus cuentas de redes sociales o de correo electrónico.
  • Open ID Connect (OIDC)es un protocolo de autenticación que se basa en OAuth 2.0. OIDC agrega una capa adicional de autenticación a OAuth 2.0, lo que significa que no solo se valida el token de acceso, sino que también se verifica la identidad del usuario que está haciendo la solicitud.
  • Json Web Token (JWT) es un formato de token que se utiliza en OAuth 2.0 y OIDC. Un JWT es un objeto JSON que se firma digitalmente y se transmite de manera segura entre dos partes. Los JWT son comúnmente utilizados en aplicaciones web y móviles para autenticar y autorizar a los usuarios.
  • OIDC Discoveryes un mecanismo que permite a los clientes descubrir información sobre un proveedor de identidad que soporta OIDC. OIDC Discovery utiliza una serie de puntos finales que proporcionan información sobre el proveedor de identidad, como el punto final de autorización, el punto final de token, y el punto final de la información del usuario.

En conclusión, estos patrones de seguridad proporcionan una capa adicional de seguridad para garantizar que la información del usuario se transmita de manera segura y que solo las personas autorizadas puedan acceder a ella.
