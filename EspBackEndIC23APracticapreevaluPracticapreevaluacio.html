Práctica preevaluación

¡Estamos llegando al final!

Estamos casi listos para entregar nuestra evaluación final en la próxima clase. A medida que avanzamos en los temas de la materia, aprendimos que desarrollar aplicaciones es un desafío muy interesante, pero para que sea un proceso bien ejecutado debemos elegir un patrón arquitectónico adecuado a las necesidades del proyecto. En aplicaciones de alta demanda, por ejemplo, es común ver implementada la arquitectura basada en microservicios como una opción para las grandes empresas, ya que este tipo de enfoque facilita el mantenimiento de los servicios de la aplicación a medida que esta se vuelve más robusta y compleja.

En este sentido, durante nuestras clases nos enfocamos precisamente en los microservicios. Pero, ¿qué experiencias hemos adquirido hasta ahora? ¿Qué temas son necesarios para dominar esta arquitectura y ejercer estos conocimientos profesionalmente? O, incluso, siendo un poco más específicos y pensando en nuestra valoración, ¿para qué temas debemos estar preparados? Entonces, basándonos en estos interrogantes, hemos enumerado a continuación los temas que debemos conocer para alcanzar todos los requisitos necesarios para aprobar este curso y que son muy relevantes en el mercado laboral:

  • Spring Cloud: proyecto de Spring que proporciona herramientas para que los desarrolladores construyan rápidamente algunos de los patrones comunes en los sistemas distribuidos
  • Resilience4j: biblioteca de tolerancia a fallas ampliamente utilizada en Circuit Breakers.
  • Zipkin: sistema de seguimiento distribuido que ayuda a recopilar los datos de tiempo necesarios para solucionar problemas de latencia en las arquitecturas de servicios.
  • RabbitMQ: es un messaging broker, es decir, un intermediario de mensajes. Brinda a sus aplicaciones una plataforma común para enviar y recibir mensajes.
  • MongoDB: programa de base de datos orientado a documentos multiplataforma. Clasificado como un programa de base de datos NoSQL, MongoDB utiliza documentos similares al formato JSON. Este es desarrollado por MongoDB Inc. y tiene licencia SSPL.
  • MySQL: sistema de gestión de base de datos que utiliza el lenguaje SQL como interfaz. Actualmente, es uno de los sistemas de administración de bases de datos más populares de Oracle Corporation, con más de 10 millones de instalaciones en todo el mundo.
  • Feign: facilita la escritura de clientes HTTP Java, a través del proyecto Spring Cloud OpenFeign.
  • API Gateway: el mismo nombre de este recurso ya anticipa su funcionalidad. En español, “gateway” significa “puerta de enlace”. Interponiéndose entre el cliente y los servicios de back end, API Gateway actúa como un proxy inverso que filtra el tráfico de todas las solicitudes y dirige los datos —y las llamadas— a la ubicación adecuada.

Todos estos temas se abordaron en las clases y son parte de las tecnologías que involucran y/o pueden usarse junto con los proyectos de Spring y que son necesarias para completar la evaluación. Por lo tanto, te sugerimos que revises todos los temas citados anteriormente, ya que son fundamentales para un buen desempeño. Entonces, ¿estás preparado?
