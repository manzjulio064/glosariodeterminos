Estructura de un formulario

Hasta el momento solo conocemos 3 formas de pedir datos a un usuario: 

        
                  // mmmm realmente no nos ayuda mucho alert
                  alert(´mensaje´);

                  // aquí solo pedimos un ´verdadero´ o ´falso´
                  confirm(´Esta seguro que desea realizar esta acción?´);

                  //ahora sí podemos pedir más información
                  prompt(´Ingrese su nombre por favor´);

Pero, ¿te imaginás usar un prompt cada vez que el usuario necesita un dato? Quizás no se lleve la mejor experiencia. Para poder obtener datos de un usuario siempre es posible utilizar los elementos que nos brinda HTML. Sabiendo esto, repasemos un poco los elementos que podemos usar.
