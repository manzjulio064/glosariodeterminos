Instalación de Keycloak

Instalación y ejecución de Keycloak

Keycloak proporciona varias opciones de instalación. Algunas de ellas son:

  • Ejecutando como un contenedor de Docker.
  • Instalando y ejecutando localmente utilizando Java.
  • Ejecutando con Kubernetes.

En este caso, dado que podemos contar con diferentes sistemas operativos, vamos a simplificar el proceso de instalación utilizando Docker como herramienta para ejecutarlo.

Recordá que ya charlamos sobre Docker en otras materias. En caso de que tengas dudas sobre qué es Docker, cómo instalarlo o cómo configurarlo recurrí a tu profesor asignado para que te ayude a re-instalarlo para poder llevar a cabo el proceso de instalación.

Ejecutando Keycloak con Docker

Abrimos una nueva terminal en nuestro sistema operativo (con Docker previamente instalado) y ejecutamos el siguiente comando: 

    
      docker run -p 8080:8080 -e KEYCLOAK_ADMIN=admin -e KEYCLOAK_ADMIN_PASSWORD=admin quay.io/keycloak/keycloak:21.0.1 start-dev

El comando de arriba nos permite ejecutar Keycloak en un contenedor de Docker. En este caso, le estamos indicando que exponga el servicio en el puerto 8080 y configuramos también las credenciales para el usuario administrador (podés poner las credenciales que quieras, como en este caso es para fines de uso local/pruebas, utilizaremos el clásico admin/admin)
