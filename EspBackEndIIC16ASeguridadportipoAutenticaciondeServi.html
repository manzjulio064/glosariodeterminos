Resumen

En esta clase abordamos cómo podemos realizar llamados internos entre microservicios utilizando un interceptor que se encarga de ejecutar un método cada vez que se envía una petición. Este método tiene como objetivo final agregar el token en el header de la solicitud a enviar.

Además, revisamos dos opciones para obtener el token. Por un lado, autenticarse utilizando las credenciales del cliente (útil cuando queremos hacerlo por fuera del contexto de un usuario). La otra opción es simplemente obtener el token que nos llega a través del gateway y reenviarlo.

En el siguiente video veremos cómo comunicar dos microservicios que requieren de un token y luego un ejercicio para resolver antes de la clase en vivo con el profe.
