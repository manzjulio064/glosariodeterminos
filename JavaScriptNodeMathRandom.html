El método Math.random() en JavaScript devuelve un número pseudoaleatorio entre 0 (inclusive) y 1 (exclusivo), es decir, un número decimal mayor o igual a 0 y menor que 1.

Ejemplo explicado:

javascript
var resultado = Math.random() < 0.3;
   console.log(resultado);

¿Qué hace este código?

  1. Math.random() genera un número aleatorio entre 0 y 1.
  2. Se compara si ese número es menor que 0.3.
  3. Si el número aleatorio es menor que 0.3, el resultado será true, de lo contrario será false.
  4. Como Math.random() genera valores de manera aleatoria, el resultado cambiará en cada ejecución.

Posibles salidas:

  • Si Math.random() genera 0.25, entonces 0.25 < 0.3 → true.
  • Si Math.random() genera 0.5, entonces 0.5 < 0.3 → false.

¿Qué devuelve Math.random() si se ejecuta solo?

Si ejecutas:

javascript
console.log(Math.random());

Obtendrás un número decimal entre 0 y 1, por ejemplo:

0.8473921
   0.1234567
   0.9999999

Cada vez que se ejecuta, el resultado cambia.

Otros ejemplos de uso de Math.random()

1. Generar un número aleatorio entre un rango específico

Si quieres generar un número entre min y max, usa:

javascript
function numeroAleatorio(min, max) {
       return Math.random() * (max - min) + min;
   }

   console.log(numeroAleatorio(5, 10)); // Un número entre 5 y 10

2. Generar un número entero aleatorio

Para obtener un número entero en un rango específico:

javascript
function numeroEnteroAleatorio(min, max) {
       return Math.floor(Math.random() * (max - min + 1)) + min;
   }

   console.log(numeroEnteroAleatorio(1, 6)); // Un número entre 1 y 6, útil para un dado

3. Simular el lanzamiento de una moneda

javascript
var moneda = Math.random() < 0.5 ? "Cara" : "Cruz";
   console.log(moneda);

Resumen

  • Math.random() devuelve un número decimal entre 0 y 1 (exclusivo).
  • Se puede usar para hacer comparaciones, como Math.random() < 0.3 (que devuelve true o false).
  • Se puede combinar con Math.floor() para obtener números enteros en un rango.
  • Es útil para simulaciones como lanzar una moneda o seleccionar elementos aleatorios.
