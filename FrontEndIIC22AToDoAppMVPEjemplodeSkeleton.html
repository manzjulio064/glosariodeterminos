Ejemplo de Skeleton

Skeleton

Ya hemos visto distintos tipos de animaciones que podemos realizar utilizando CSS y Javascript, y de qué manera dichas animaciones nos ayudan a dar feedback al usuario. Pero, antes de dar por concluido este tópico, queremos mostrarte una alternativa más.

Si bien el uso de barras de carga y spinners representa un gran recurso a la hora de indicar que nuestra aplicación se encuentra realizando algún tipo de petición o proceso, en el último tiempo ha surgido un nuevo tipo de animación muy popular entre los desarrolladores: los skeletons ?.

¿Qué es un skeleton? Bueno, para responder esa pregunta, te invitamos a que ingreses a Youtube. Si prestas atención verás que en un primer momento, apenas se carga la página, aparecen una serie de elementos no contienen información sobre los videos (la que aparecerá segundos después) sino que dichos elementos actúan como una especie de placeholders de la información que la aplicación se encuentra solicitando al servidor.

Esos placeholders no son otra cosa que los skeletons. Su uso ha ido ganando popularidad entre los diseñadores y desarrolladores ya que, a diferencia de los spinners y barra de carga, brindan a la persona que accede al sitio, una representación visual del layout y contenido que tendrá la página una vez obtenida la información que se encuentra pendiente de carga. De esta manera, se obtiene una interfaz mucho más amigable y representativa del sitio en su totalidad.

A esta altura puede que te preguntes si crear un skeleton puede llegar a ser algo complicado. Bueno, la realidad es que no lo es. Solo hace falta un poco de HTML y CSS y listo, tendremos un skeleton listo para usar. ¿No nos crees? Veamos un ejemplo:

Paso a paso: construyendo nuestro primer skeleton

Para poder construir nuestro skeleton comenzaremos creando un archivo index.html que contendrá la estructura básica de este tipo de documentos: 

        
                  <!DOCTYPE html>
                  <html lang="en">
                  <head>
                      <meta charset="UTF-8" />
                      <meta http-equiv="X-UA-Compatible" content="IE=edge" />
                      <meta name="viewport" content="width=device-width, initial-scale=1.0" />
                      <title>Loading Skeleton</title>
                  </head>
                  <body></body>
                  </html>

TIP: Puedes inicializar rápidamente un documento HTML en tu VS Code tipeando el carácter “ ! ” seguido de la tecla Tab.

Ahora que ya tenemos el documento inicializado, incorporaremos dentro del body los elementos necesarios para renderizar nuestro skeleton: 

        
                   <body>
                       <h1>Loading Skeleton </h1>
                       <div class="card">
                         <div class="skeleton image-loader"> </div>
                         <div class="card-content">
                           <div class="skeleton avatar-loader"> </div>
                           <div class="text-content">
                             <div class="skeleton text-loader"> </div>
                             <div class="skeleton text-loader"> </div>
                           </div>
                         </div>
                       </div>
                     </body>

Seguidamente, incorporaremos algunos estilos. Para ello, crearemos un archivo styles.css (no olvides incluir este archivo en el index.html) y agregaremos los siguientes estilos: 

        
                  body {
                      font-family: sans-serif;
                      margin: 0;
                      padding: 0;
                      box-sizing: border-box;
                      display: flex;
                      flex-direction: column;
                      justify-content: center;
                      align-items: center;
                      background: whitesmoke;
                     }

                     .skeleton {
                      width: 100%;
                      animation: loadingAnimation 1.5s infinite;
                     }

                     .card {
                      width: 300px;
                      height: auto;
                      display: flex;
                      flex-direction: column;
                      justify-content: center;
                      align-items: center;
                      padding: 0.2rem;
                      background: white;
                      box-shadow: 4px 4px 4px lightgray;
                     }

                     .image-loader {
                      height: 200px;
                      width: 100%;
                      border: 2px solid white;
                     }

                     .card-content {
                      display: flex;
                      width: 100%;
                      display: flex;
                      justify-content: space-evenly;
                      margin-top: 0.5rem;
                      margin-bottom: 0.5rem;
                     }

                     .avatar-loader {
                      border-radius: 50%;
                      height: 70px;
                      width: 70px;
                     }

                     .text-content {
                      width: 70%;
                      display: flex;
                      flex-direction: column;
                      justify-content: center;
                      align-items: center;
                     }

                     .text-loader {
                      width: 100%;
                      height: 20px;
                      margin: 0.3rem;
                     }

                     @keyframes loadingAnimation {
                      0% {
                        background: white;
                      }
                      50% {
                        background: rgb(182, 177, 177);
                      }
                      100% {
                        background: white;
                      }
                     }

Como puede verse del código anterior, utilizamos keyframes para animar nuestro skeleton, lo que dará la sensación de movimiento propia de una verdadera animación. De esta manera, la persona que lo vea podrá hacerse la idea de que la aplicación se encuentra activa, realizando una determinada petición o proceso.

¡Excelente! A esta altura ya tienes un skeleton animado y totalmente funcional.?
