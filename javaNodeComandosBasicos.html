Variables en JavaScript

Las variables son espacios donde podemos almacenar información para usarla más adelante.

  • var: Se utiliza para declarar una variable global. Sin embargo, hoy en día se recomienda usar let o const en su lugar, porque var puede generar problemas en algunos casos.
  • let: Declara una variable con un ámbito de bloque, es decir, solo existe dentro de la función o bloque donde se declaró.

Funciones y operadores matemáticos

Son herramientas que nos ayudan a realizar operaciones matemáticas.

  • Math.round(): Redondea un número decimal al entero más cercano. Por ejemplo, Math.round(4.6) devolverá 5, y Math.round(4.3) devolverá 4.
  • Ternario: Es una forma abreviada de escribir un if. La estructura es: 
    javascript
    condición ? valor_si_verdadero : valor_si_falso;
    Por ejemplo: 
    javascript
    let edad = 18;
   let mensaje = (edad >= 18) ? "Eres mayor de edad" : "Eres menor de edad";

Estructuras de Control

Son instrucciones que nos permiten ejecutar diferentes partes del código según ciertas condiciones.

  • Switch: Es una alternativa a múltiples if-else. Permite evaluar una variable con varios posibles valores. 
    javascript
    let fruta = "manzana";
   switch (fruta) {
     case "manzana":
       console.log("Es una manzana");
       break;
     case "banana":
       console.log("Es una banana");
       break;
     default:
       console.log("Fruta desconocida");
   }
  • typeof: Nos dice el tipo de dato de una variable. Ejemplo: 
    javascript
    console.log(typeof "Hola"); // Devuelve "string"
   console.log(typeof 10); // Devuelve "number"

Manejo de Cadenas de Texto (Strings)

Funciones útiles para trabajar con texto.

  • .length: Devuelve la cantidad de caracteres en un string. Ejemplo: 
    javascript
    let palabra = "Hola";
   console.log(palabra.length); // Devuelve 4
  • .toUpperCase(): Convierte el texto a mayúsculas. 
    javascript
    console.log("hola".toUpperCase()); // Devuelve "HOLA"
  • .charAt(): Obtiene un carácter en una posición específica. 
    javascript
    console.log("Hola".charAt(1)); // Devuelve "o"
  • .slice(): Extrae una parte de un string. 
    javascript
    console.log("JavaScript".slice(0,4)); // Devuelve "Java"
  • .trim(): Elimina espacios al inicio y al final de un string. 
    javascript
    console.log("  Hola  ".trim()); // Devuelve "Hola"
  • .replace(): Reemplaza una parte del texto por otra. 
    javascript
    console.log("Hola mundo".replace("mundo", "amigo")); // Devuelve "Hola amigo"
  • .split(): Divide un string en un array de palabras. 
    javascript
    console.log("Hola mundo".split(" ")); // Devuelve ["Hola", "mundo"]

Manejo de Arrays (Listas)

Funciones útiles para manipular listas de elementos.

  • .push(): Agrega un elemento al final del array. 
    javascript
    let numeros = [1, 2, 3];
   numeros.push(4);
   console.log(numeros); // [1, 2, 3, 4]
  • .pop(): Elimina el último elemento del array. 
    javascript
    let frutas = ["manzana", "banana", "uva"];
   frutas.pop();
   console.log(frutas); // ["manzana", "banana"]
  • .shift(): Elimina el primer elemento del array. 
    javascript
    let colores = ["rojo", "azul", "verde"];
   colores.shift();
   console.log(colores); // ["azul", "verde"]
  • .unshift(): Agrega elementos al principio del array. 
    javascript
    let animales = ["perro", "gato"];
   animales.unshift("elefante");
   console.log(animales); // ["elefante", "perro", "gato"]
  • .join(): Convierte un array en un string con un separador. 
    javascript
    let palabras = ["Hola", "mundo"];
   console.log(palabras.join(" ")); // "Hola mundo"
  • .indexOf(): Devuelve la posición de un elemento en un array. 
    javascript
    let numeros = [10, 20, 30, 40];
   console.log(numeros.indexOf(30)); // 2
  • .includes(): Verifica si un elemento está en el array. 
    javascript
    console.log([1, 2, 3].includes(2)); // true

Bucles (Loops)

Permiten repetir un bloque de código varias veces.

  • for: Se usa cuando sabemos cuántas veces queremos repetir algo. 
    javascript
    for (let i = 0; i < 5; i++) {
     console.log("Hola");
   }
  • while: Se usa cuando queremos repetir algo mientras una condición sea verdadera. 
    javascript
    let x = 0;
   while (x < 5) {
     console.log(x);
     x++;
   }
  • do while: Se ejecuta al menos una vez antes de verificar la condición. 
    javascript
    let y = 0;
   do {
     console.log(y);
     y++;
   } while (y < 5);

Funciones y Callbacks

  • Funciones Constructoras: Son plantillas para crear objetos. 
    javascript
    function Persona(nombre, edad) {
     this.nombre = nombre;
     this.edad = edad;
   }
   let persona1 = new Persona("Juan", 30);
   console.log(persona1.nombre); // "Juan"
  • this: Se refiere al objeto actual dentro de una función o clase.
  • Callback: Es una función que se pasa como argumento a otra función. 
    javascript
    function procesar(num, callback) {
     console.log(callback(num));
   }
   procesar(5, (x) => x * 2); // Devuelve 10

Funciones para Arrays

  • map(): Crea un nuevo array con los resultados de aplicar una función a cada elemento. 
    javascript
    let numeros = [1, 2, 3];
   let cuadrados = numeros.map(n => n * n);
   console.log(cuadrados); // [1, 4, 9]
  • filter(): Filtra los elementos de un array según una condición. 
    javascript
    let mayores = [10, 20, 30].filter(n => n > 15);
   console.log(mayores); // [20, 30]
  • reduce(): Reduce un array a un solo valor. 
    javascript
    let suma = [1, 2, 3, 4].reduce((acc, num) => acc + num, 0);
   console.log(suma); // 10
